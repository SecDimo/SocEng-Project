# SocEng-Project# Phishing Awareness Campaign Toolkit

Authorized social engineering toolkit for the Macomb College Vulnerability Analysis Report.

## Files

|File           |Purpose                                                   |
|---------------|----------------------------------------------------------|
|`sender.py`    |Sends phishing emails with unique tracking links          |
|`server.py`    |Tracking server — logs clicks and shows awareness page    |
|`targets.csv`  |Your target list (name,email) — fill this in              |
|`targets.json` |Auto-generated by sender.py — maps tracking IDs to targets|
|`send_log.csv` |Auto-generated — log of every email sent                  |
|`click_log.csv`|Auto-generated — log of every link clicked                |

## Setup

### 1. Install dependencies

```
pip install flask
```

### 2. Create a Gmail account for sending

- Create a new Gmail account (NOT your macomb.edu email)
- Enable 2-Factor Authentication
- Go to myaccount.google.com > Security > App Passwords
- Generate an app password and paste it into sender.py

### 3. Fill in targets.csv

Add staff/employee emails — one per row:

```
name,email
John Smith,smithj@macomb.edu
```

### 4. Deploy the tracking server

Free options:

- **PythonAnywhere** (pythonanywhere.com) — free tier, easiest for Flask
- **Render** (render.com) — free tier for web services
- **Railway** (railway.app) — free starter tier

Once deployed, copy your server URL into sender.py (`TRACKING_SERVER_URL`).
Also upload `targets.json` (generated by sender.py) to the server directory.

### 5. Update sender.py config

Edit the CONFIG section at the top:

- SMTP credentials
- TRACKING_SERVER_URL
- PROFESSOR_EMAIL is already set

### 6. Run the sender

```
python sender.py
```

### 7. Monitor results

Visit `https://your-server-url.com/dashboard` to see:

- Total emails sent
- Unique clicks
- Click rate
- Full click log with timestamps

## Workflow

1. Fill targets.csv → 2. Run sender.py → 3. Copy targets.json to server →
1. Start server.py → 5. Monitor /dashboard → 6. Export click_log.csv for report
